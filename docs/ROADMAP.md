## 🔄 Step-by-Step Execution Guide

---

### 🟢 STEP 0 & 0.5 — Question Selection & Approach Decision

#### 🎯 Goal:
Determine the problem type (**Type A**, **Type B**, or **Type C**) to fix the exact scene count and structure before writing any script.

#### 5 Decision Rules:
1. **Rule D1**: Does the brute force teach *"WHY we need this technique?"*
   - `YES` → Type B or C
   - `NO` → Direct Optimal (Type A)
2. **Rule D2**: Does a "better" middle approach teach a *distinct new concept*?
   - `YES` → Type C (3 approaches, 10 scenes)
   - `NO` → Type B (2 approaches, 8 scenes) or Type A (1 approach, 6 scenes)
3. **Rule D3**: DP problems naturally follow Type C (Recursion → Memoization → Tabulation).
4. **Rule D4**: Pure Data Structure problems (Stack, Trie, Heap) use Type A (6 scenes).
5. **Rule D5**: When in doubt, fewer approaches is better for beginner retention.

#### 📄 Output File: `analysis.json`
```json
{
  "question": "Contains Duplicate",
  "leetcode": 217,
  "pattern": "Arrays & Hashing",
  "pattern_number": 1,
  "question_number": 1,
  "difficulty": "Easy",
  "approach_type": "B",
  "scene_count": 8,
  "approaches": {
    "brute": {
      "technique": "Nested loops checking every pair (i, j)",
      "time": "O(n²)",
      "space": "O(1)",
      "teaches": "Shows WHY comparing all pairs is wasteful."
    },
    "optimal": {
      "technique": "HashSet membership check before inserting",
      "time": "O(n)",
      "space": "O(n)"
    }
  },
  "decision_reasoning": {
    "D1_brute_teaches_why": "YES — creates the 'why HashSet?' moment."
  }
}
```

🛑 **GATE 0.5 APPROVAL**: Stop. Human must approve `analysis.json` before moving to Step 1.

#### 📏 Script Rules:

2. **Trace Two-Part Structure**:

4. **Predict**: Always includes a sacred **3-second silent countdown** (3... 2... 1).

### 🟢 STEP 4 — Frame-by-Frame Sync Plan

#### 🎯 Goal:
Map every visual transition, pointer movement, comparison glow, and code highlight to exact audio frame numbers derived from Step 3.

#### 📏 Planning Rules:
- **Rule 9**: Animation syncs to your voice — frame numbers must come directly from `sync/*.json`.
- **Rule 6**: One idea per frame — state changes happen first, position moves second.

#### 📄 Output: `plans/<scene-id>.plan.json`
```json
{
  "scene": "04-trace-brute",
  "total_frames": 1152,
  "keyframes": [
    {
      "frame": 0,
      "action": "mount_array",
      "data": {"array": [3, 7, 1, 4, 1, 9, 2]}
    },
    {
      "frame": 180,
      "action": "pointer_compare",
      "i": 0,
      "j": 1,
      "audio_word": "seven"
    }
  ]
}
```

🛑 **GATE 4 APPROVAL**: Stop. Human reviews the timing plan before writing Remotion code.

### 🟢 STEP 5 — Remotion Animation Code

#### 🎯 Goal:
Implement React / Remotion scene components based on the approved sync plans and design system.

#### 🎨 Design System & Animation Laws:
1. **Canvas**: Deep Indigo (`#1A1035`)
2. **State Palette**:
   - `idle`: `#1E1540` / `#3D2D6B`
   - `scanning`: `#0A2A3D` / `#00D4FF` (Cyan)
   - `comparing`: `#3D2A00` / `#FFB800` (Gold)
   - `settled`: `#0A2D20` / `#2ED8A3` (Mint)
   - `target/error`: `#3D1520` / `#FF6B6B` (Coral)
3. **No CSS animations or keyframes**: All animations driven by `useCurrentFrame()`, `interpolate()`, and `spring()`.
4. **Determinism**: Use `random('seed')`, never `Math.random()`.
5. **Shared Component Reuse**: Use components from `shared/components/` (e.g. `ComplexityCurve.tsx`, `ArrayCell.tsx`, `CodePanel.tsx`).

🛑 **GATE 5 APPROVAL**: Human previews scenes locally in Remotion Studio (`npm run start`).

---

### 🟢 STEP 6 — Final Assembly, QA Checklist & Render

#### 🎯 Goal:
Verify all anti-patterns and render the final high-definition video.

#### ✅ 24-Point Pre-Render Checklist:
- [ ] Safe area compliance (no elements clipped at 1920×1080 borders)
- [ ] Layer names specified on every `<Sequence>` and `<Interactive.*>`
- [ ] No `Math.random()` used anywhere
- [ ] All `interpolate()` calls are strictly clamped: `extrapolateLeft: 'clamp', extrapolateRight: 'clamp'`
- [ ] Audio levels balanced across all scene tracks
- [ ] Total frame duration matches audio sync duration exactly

#### 💻 Render Command:
```bash
npx remotion render src/Root.tsx ContainsDuplicate output/video.mp4
```

🛑 **FINAL GATE**: Human reviews and approves `output/video.mp4`.
