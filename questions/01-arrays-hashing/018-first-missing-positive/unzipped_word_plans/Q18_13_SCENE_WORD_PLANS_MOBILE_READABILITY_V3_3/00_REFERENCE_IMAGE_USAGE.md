# Q18 Reference Image Usage Guide

This package includes two approved reference images:
- `REF_MOBILE_STYLE_TRACE_FRAME.png`
- `REF_MOBILE_STYLE_CODE_FRAME.png`

Use them as style guidance for:
- typography size hierarchy
- chalk stroke thickness
- board contrast
- section spacing
- title emphasis
- array readability
- code readability
- 16:9 composition

## Important
These are not exact templates to blindly copy.
They are visual benchmarks for readability and weight.

## How to use them

### For trace scenes (03, 06, 10)
Follow `REF_MOBILE_STYLE_TRACE_FRAME.png` for:
- variable sidebar readability
- large array cells
- prominent active value highlight
- clear right-side reasoning stack
- large final answer line at bottom

### For code scenes (04, 07, 11)
Follow `REF_MOBILE_STYLE_CODE_FRAME.png` for:
- larger code text
- highlighted active line
- short explanation bullets on the right
- clearer problem header / section header hierarchy

### For non-trace, non-code scenes
Borrow the same readability principles:
- large enough text
- brighter emphasis
- fewer things at once
- stronger hierarchy
