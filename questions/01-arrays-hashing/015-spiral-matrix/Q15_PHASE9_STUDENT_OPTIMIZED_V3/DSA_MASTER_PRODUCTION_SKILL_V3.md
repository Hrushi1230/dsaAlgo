# DSA MASTER PRODUCTION SKILL V3
## Code With Animation — Authoritative for All Future Questions

> **Highest-priority reusable rule:** use this production discipline for every new long-form DSA question unless the user explicitly changes it.
>
> Do not copy previous-question visuals. Copy the rigor, verification, kit-first architecture, word-driven timing discipline, and QA loop.

---

# 1. MASTER PIPELINE — 18 PHASES

```text
01 Problem Research
02 Best Master Example
03 Actual Dry Run
04 Independent Re-check
05 Verified Teaching Trace
06 Scene Structure Planning
07 Full Narration Script
08 Script Verification
09 Word-Based Visual Planning
10 Final ElevenLabs Audio — USER
11 Exact Word-Sync JSON — USER
12 Exact Frame-Wise Plan — ANTIGRAVITY
13 Implementation in Antigravity
14 Typecheck + Algorithm QA
15 Render + Visual + Motion QA
16 Cross-Scene Continuity QA
17 Final Question Production Audit

```

Core law:

```text
RESEARCH → VERIFY → TEACH → PLAN BY WORDS
→ USER AUDIO/SYNC → EXACT FRAMES → IMPLEMENT → QA
```

Never skip verification.

# 2. NO-GUESS LAW

```text
INSPECT → VERIFY → AUDIT → THEN CREATE
```

Never guess:
- algorithm state;
- pointer state;
- matrix/array geometry;
- component APIs;
- roadmap state;
- complexity;
- audio timing;
- frames;
- code branches;
- visual persistence;
- local counters;
- future results.

If source is missing:

```text
UNRESOLVED — SOURCE REQUIRED
```

---

# 3. METHOD RESEARCH LAW

For each question:

1. Find all real solution methods worth teaching.
2. Reject cosmetic variants.
3. Choose a master testcase that exposes the hard invariant.
4. Dry-run every taught method manually.
5. Re-check from scratch independently.
6. Lock exact states and edge cases.
7. Only then build teaching trace.

---

# 4. TRACE → CODE IDENTITY LAW

For every method:

```text
TRACE
→ SAME EXECUTION
→ CODE
→ SAME COMPLEXITY ANALYSIS
```

Never trace one correct organization and code another.

If mismatch is found:
```text
rewrite trace/script first
→ re-audit
→ then continue
```

# 10. KIT-FIRST / FOUNDATION-FIRST LAW

For every needed structure:

```text
NEED STRUCTURE
→ inspect actual @dsa/kit / production component
→ REUSE
→ if small ability missing: EXTEND reusable kit
```

Forbidden:

- generic boxes for DSA structures;
- duplicate roadmap UI;
- fake editor;
- generic HTML table;
- manual one-off SVG when kit supports the concept.

Conceptual does not mean generic.

# 21. ANTIGRAVITY POST-AUDIO CONTRACT

After MP3 + exact sync:

```text
Phase9 plan
+ final MP3
+ exact sync
↓
anchor → word IDs
↓
word IDs → seconds
↓
seconds → frames @ 30fps
↓
exact frame plan
↓
audit
↓
implement
```

Frame convention:

```text
[startFrame,endFrameExclusive)
```

At 30fps:

```text
startFrame = floor(start × 30)
endFrameExclusive = max(startFrame + 1, ceil(end × 30))
```

Antigravity owns:
```text
WHEN
WORD ID
SECOND
FRAME
```

Phase9 owns:
```text
WHAT
WHY
ORDER
STATE
CAUSE/EFFECT
ENTER
EXIT
PERSISTENCE
KIT INTENT
```

Do not redesign after sync.

# 22. REAL HOLD LAW

Only real audio gap creates a comprehension hold.

```text
gap = nextAnchor.start - currentAnchor.end
```

If gap <= 0:
```text
NO HOLD
```

Never invent 10/15/20 frame holds.

---

# 23. CODE CHARACTER TYPING AFTER SYNC

If character-level timing exists:
```text
use exact character timing
```

If only word-level timing exists:
1. map spoken code token to exact word window;
2. distribute that token’s characters deterministically inside the word window;
3. attach unspoken syntax to nearest associated token;
4. whitespace gets no semantic delay;
5. never use generic chars-per-frame speed.
